# src/_includes/partials/

Target-system rendering partials — consume `content/{track}/*.json`, own no content of their own.

- `chapter.njk` — one chapter; dispatches `content.blocks[]` to `blocks/*.njk` by `kind`
- `blocks/{callout,table,cards,text,explorer}.njk` — one per `course_schema.json` block kind
- `subject-head.njk`, `rail.njk`, `test-generator.njk`, `downloads-block.njk`, `practice-set.njk` —
  page-level sections outside the chapter loop
- `_bilingual.njk` — shared macro every partial above uses for `{en,ar}` fields; don't interpolate
  `field.en`/`field.ar` directly in a new partial, always go through this (`docs/DECISIONS/0004`)

Does NOT contain: legacy-system templates (`src/_includes/tracks/*.html` — generated by `build.js`, never
hand-edited) or `base.njk` (the shared page shell, one level up).
