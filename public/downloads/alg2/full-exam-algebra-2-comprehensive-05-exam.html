To simplify the rational expression x2−252x−10\dfrac{x^2 - 25}{2x - 10}2x−10x2−25​, factor both the numerator and the denominator completely:

Consider the rational equation
x+1x−3+kx+1=x+13x2−2x−3\frac{x + 1}{x - 3} + \frac{k}{x + 1} = \frac{x + 13}{x^2 - 2x - 3}x−3x+1​+x+1k​=x2−2x−3x+13​
where kkk is a constant. What is the sum of all real values of kkk for which the equation has no real solution?
A. −7-7−7
B. −3-3−3
C. −10-10−10
D. 101010
Correct Answer: (C) — −10-10−10
Step 1: Determine the restricted values from the denominators.
The denominators are x−3x - 3x−3, x+1x + 1x+1, and x2−2x−3=(x−3)(x+1)x^2 - 2x - 3 = (x - 3)(x + 1)x2−2x−3=(x−3)(x+1). Thus, the domain of the equation is all real numbers except x=3x = 3x=3 and x=−1x = -1x=−1.

Step 2: Clear the denominators by multiplying both sides by (x−3)(x+1)(x - 3)(x + 1)(x−3)(x+1):
(x+1)2+k(x−3)=x+13(x + 1)^2 + k(x - 3) = x + 13(x+1)2+k(x−3)=x+13

Step 3: Expand and rewrite as a standard quadratic equation:
(x2+2x+1)+kx−3k=x+13(x^2 + 2x + 1) + kx - 3k = x + 13(x2+2x+1)+kx−3k=x+13
x2+(k+1)x−(3k+12)=0x^2 + (k + 1)x - (3k + 12) = 0x2+(k+1)x−(3k+12)=0

Step 4: Factor the quadratic equation.
Notice that substituting x=3x = 3x=3 gives:
32+3(k+1)−(3k+12)=9+3k+3−3k−12=03^2 + 3(k + 1) - (3k + 12) = 9 + 3k + 3 - 3k - 12 = 032+3(k+1)−(3k+12)=9+3k+3−3k−12=0
Since x=3x = 3x=3 is always a root, the quadratic factors as:
(x−3)(x+k+4)=0(x - 3)(x + k + 4) = 0(x−3)(x+k+4)=0
Therefore, the solutions to the cleared equation are x=3x = 3x=3 and x=−(k+4)x = -(k + 4)x=−(k+4).

Step 5: Identify extraneous solutions.
Since x=3x = 3x=3 makes the denominator zero, it is an extraneous solution for every value of kkk. For the original equation to have no real solution, the other root x=−(k+4)x = -(k + 4)x=−(k+4) must also be extraneous, meaning it must equal one of the excluded values (333 or −1-1−1):

- Case 2: −(k+4)=−1  ⟹  k+4=1  ⟹  k=−3-(k + 4) = -1 \implies k + 4 = 1 \implies k = -3−(k+4)=−1⟹k+4=1⟹k=−3

Step 6: Compute the sum of the values of kkk:
(−7)+(−3)=−10(-7) + (-3) = -10(−7)+(−3)=−10

- Identifying only k=−7k = -7k=−7 accounts for the repeated extraneous root at x=3x = 3x=3 but misses that x=−1x = -1x=−1 also invalidates the solution.
