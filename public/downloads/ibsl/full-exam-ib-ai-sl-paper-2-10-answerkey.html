Consider the function f(x)=x2−4x+3f(x) = x^2 - 4x + 3f(x)=x2−4x+3. The graph of this function is shown below. Find the y-intercept of the graph.

(a) Write down the key mathematical relationship or initial equation required to model this problem. [4 marks]
(b) Hence, or otherwise, find the exact required analytical solution, showing all working clearly. [8 marks]
Official Examiner Mark Scheme [12 marks] — Final Answer: 333
The y-intercept of a function is the value of the function when x=0x=0x=0. For the function f(x)=x2−4x+3f(x) = x^2 - 4x + 3f(x)=x2−4x+3, we can find the y-intercept by substituting x=0x=0x=0: \\ f(0) = (0)^2 - 4(0) + 3 \\ f(0) = 0 - 0 + 3 \\ f(0) = 3 \\ Thus, the y-intercept is 3. [M1] [A1]
