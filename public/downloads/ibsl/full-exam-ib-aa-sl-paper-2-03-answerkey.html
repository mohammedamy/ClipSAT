Consider the function f(x)=x3−6x2+5f(x) = x^3 - 6x^2 + 5f(x)=x3−6x2+5. The graph of y=f(x)y = f(x)y=f(x) is shown below. Determine the coordinates of the local maximum of f(x)f(x)f(x).

(a) Write down the key mathematical relationship or initial equation required to model this problem. [2 marks]
(b) Hence, or otherwise, find the exact required analytical solution, showing all working clearly. [5 marks]
Official Examiner Mark Scheme [7 marks] — Final Answer: (0,5)(0, 5)(0,5)
To find the local maximum of the function f(x)=x3−6x2+5f(x) = x^3 - 6x^2 + 5f(x)=x3−6x2+5, we first need to find the critical points by taking the derivative and setting it to zero.

1. Find the first derivative:
f′(x)=ddx(x3−6x2+5)=3x2−12xf'(x) = \frac{d}{dx}(x^3 - 6x^2 + 5) = 3x^2 - 12xf′(x)=dxd​(x3−6x2+5)=3x2−12x

2. Set the derivative to zero and solve for xxx:
3x2−12x=03x^2 - 12x = 03x2−12x=0
3x(x−4)=03x(x - 4) = 03x(x−4)=0
This gives critical points at x=0x = 0x=0 and x=4x = 4x=4.

3. Use the second derivative test to determine if these points are local maxima or minima.
Find the second derivative:
f′′(x)=ddx(3x2−12x)=6x−12f''(x) = \frac{d}{dx}(3x^2 - 12x) = 6x - 12f′′(x)=dxd​(3x2−12x)=6x−12

4. Evaluate the second derivative at the critical points:
At x=0x = 0x=0: f′′(0)=6(0)−12=−12f''(0) = 6(0) - 12 = -12f′′(0)=6(0)−12=−12. Since f′′(0)<0f''(0) < 0f′′(0)<0, x=0x = 0x=0 corresponds to a local maximum.
At x=4x = 4x=4: f′′(4)=6(4)−12=24−12=12f''(4) = 6(4) - 12 = 24 - 12 = 12f′′(4)=6(4)−12=24−12=12. Since f′′(4)>0f''(4) > 0f′′(4)>0, x=4x = 4x=4 corresponds to a local minimum.

5. Find the y-coordinate of the local maximum by substituting x=0x = 0x=0 into the original function:
f(0)=(0)3−6(0)2+5=5f(0) = (0)^3 - 6(0)^2 + 5 = 5f(0)=(0)3−6(0)2+5=5

Therefore, the coordinates of the local maximum are (0, 5).

Common errors include: mistaking a local minimum for a local maximum, only finding the x-coordinate without the y-coordinate, or making algebraic errors in differentiation or solving equations. [M1] [A1]

Since the graph of f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c passes through the given points, we can form a system of linear equations by substituting the coordinates of these points into the function's equation:
