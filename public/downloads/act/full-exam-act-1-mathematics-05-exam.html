Which of the following expressions is equivalent to (5x2−2x+7)−(3x2−6x−4)(5x^2 - 2x + 7) - (3x^2 - 6x - 4)(5x2−2x+7)−(3x2−6x−4)?

B. 2x2+4x+32x^2 + 4x + 32x2+4x+3
C. 2x2+4x+112x^2 + 4x + 112x2+4x+11

Correct Answer: (C) — 2x2+4x+112x^2 + 4x + 112x2+4x+11

−(3x2−6x−4)=−3x2+6x+4-(3x^2 - 6x - 4) = -3x^2 + 6x + 4−(3x2−6x−4)=−3x2+6x+4

Now rewrite the entire expression and combine like terms:

(5x2−2x+7)−3x2+6x+4(5x^2 - 2x + 7) - 3x^2 + 6x + 4(5x2−2x+7)−3x2+6x+4

Group terms with the same power of xxx:
- Quadratic terms: 5x2−3x2=2x25x^2 - 3x^2 = 2x^25x2−3x2=2x2
- Linear terms: −2x+6x=4x-2x + 6x = 4x−2x+6x=4x
- Constant terms: 7+4=117 + 4 = 117+4=11

Combining these yields 2x2+4x+112x^2 + 4x + 112x2+4x+11.

Common misconceptions:
- Failing to distribute the negative sign to −6x-6x−6x yields −2x−6x=−8x-2x - 6x = -8x−2x−6x=−8x, producing the distractor 2x2−8x+112x^2 - 8x + 112x2−8x+11.
