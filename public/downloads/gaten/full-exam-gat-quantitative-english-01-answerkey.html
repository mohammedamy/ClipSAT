16 Ratios, Proportion & Percentages Foundational [1 mark]
In a factory that produces pens, the ratio of the number of blue pens to the number of red pens is 5:35:35:3. If the number of blue pens exceeds the number of red pens by 40 pens, what is the total number of blue and red pens in the factory?
A. 100100100
B. 160160160 ✓
C. 120120120
D. 200200200
Correct Answer: (B) — 160160160
Let BBB be the number of blue pens and RRR be the number of red pens.
We know that the ratio BR=53\frac{B}{R} = \frac{5}{3}RB​=35​.
We can write B=5kB = 5kB=5k and R=3kR = 3kR=3k for some constant kkk.
It is given that the number of blue pens exceeds the number of red pens by 40 pens, so B−R=40B - R = 40B−R=40.
Substituting the values of BBB and RRR in terms of kkk: 5k−3k=405k - 3k = 405k−3k=40.
Thus, 2k=402k = 402k=40, which implies k=20k = 20k=20.
The total number of pens is B+R=5k+3k=8kB + R = 5k + 3k = 8kB+R=5k+3k=8k.
Substituting the value of kkk: 8×20=1608 \times 20 = 1608×20=160.
