10 Sequences & Patterns Foundational [1 mark]
What is the next term in the following arithmetic sequence: 3, 7, 11, 15, ...?
A. 202020
B. 171717
C. 191919 ✓
D. 181818
Correct Answer: (C) — 191919
المتتابعة هي متتابعة حسابية لأن الفرق بين كل حدين متتاليين ثابت.
الفرق = 7 - 3 = 4.
الفرق = 11 - 7 = 4.
الفرق = 15 - 11 = 4.
إذن، الفرق المشترك هو 4.
لإيجاد الحد التالي، نضيف الفرق المشترك إلى الحد الأخير.
الحد التالي = 15 + 4 = 19.
The sequence is an arithmetic sequence because the difference between consecutive terms is constant.
Difference = 7 - 3 = 4.
Difference = 11 - 7 = 4.
Difference = 15 - 11 = 4.
Thus, the common difference is 4.
To find the next term, we add the common difference to the last term.
Next term = 15 + 4 = 19.
