1 Functions (HL Extensions) Standard [27 marks]
The diagram shows the graph of the quadratic function f(x)=ax2+bx−2f(x) = ax^2 + bx - 2f(x)=ax2+bx−2. The graph passes through the points (1,−3)(1, -3)(1,−3) and (2,2)(2, 2)(2,2). Determine the value of aaa.

(a) Write down the key mathematical relationship or initial equation required to model this problem. [10 marks]
(b) Hence, or otherwise, find the exact required analytical solution, showing all working clearly. [17 marks]
Official Examiner Mark Scheme [27 marks] — Final Answer: 333
The function is given by f(x)=ax2+bx−2f(x) = ax^2 + bx - 2f(x)=ax2+bx−2.
Since the graph passes through (1,−3)(1, -3)(1,−3), we have f(1)=−3f(1) = -3f(1)=−3:
a(1)2+b(1)−2=−3a(1)^2 + b(1) - 2 = -3a(1)2+b(1)−2=−3
a+b−2=−3a + b - 2 = -3a+b−2=−3
a+b=−1a + b = -1a+b=−1 (Equation 1)

Since the graph passes through (2,2)(2, 2)(2,2), we have f(2)=2f(2) = 2f(2)=2:
a(2)2+b(2)−2=2a(2)^2 + b(2) - 2 = 2a(2)2+b(2)−2=2
4a+2b−2=24a + 2b - 2 = 24a+2b−2=2
4a+2b=44a + 2b = 44a+2b=4
2a+b=22a + b = 22a+b=2 (Equation 2)

Now we solve the system of linear equations for aaa and bbb.
Subtract Equation 1 from Equation 2:
(2a+b)−(a+b)=2−(−1)(2a + b) - (a + b) = 2 - (-1)(2a+b)−(a+b)=2−(−1)
a=3a = 3a=3

Substitute a=3a = 3a=3 into Equation 1:
3+b=−13 + b = -13+b=−1
b=−4b = -4b=−4

Thus, the function is f(x)=3x2−4x−2f(x) = 3x^2 - 4x - 2f(x)=3x2−4x−2. The value of aaa is 3. [M1] [A1]
