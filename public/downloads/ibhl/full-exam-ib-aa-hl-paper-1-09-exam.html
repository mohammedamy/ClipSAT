The function is given by f(x)=x2−4x+3f(x) = x^2 - 4x + 3f(x)=x2−4x+3. To find the local minimum, we first find the derivative of the function: f′(x)=2x−4f'(x) = 2x - 4f′(x)=2x−4. We set the derivative to zero to find the critical points: 2x−4=02x - 4 = 02x−4=0, which gives x=2x = 2x=2. To confirm this is a minimum, we can find the second derivative: f′′(x)=2f''(x) = 2f′′(x)=2. Since f′′(2)=2>0f''(2) = 2 > 0f′′(2)=2>0, the critical point at x=2x = 2x=2 corresponds to a local minimum. Now we find the y-coordinate by substituting x=2x = 2x=2 into the original function: f(2)=(2)2−4(2)+3=4−8+3=−1f(2) = (2)^2 - 4(2) + 3 = 4 - 8 + 3 = -1f(2)=(2)2−4(2)+3=4−8+3=−1. Therefore, the coordinates of the local minimum are (2, -1). [M1] [A1]
