Since b=2ab = 2ab=2a, we have a−2a+c=8  ⟹  −a+c=8a - 2a + c = 8 \implies -a + c = 8a−2a+c=8⟹−a+c=8.

The graph also passes through the point (1,0)(1, 0)(1,0). So, f(1)=0f(1) = 0f(1)=0. Substituting x=1x = 1x=1 into the function: a(1)2+b(1)+c=0  ⟹  a+b+c=0a(1)^2 + b(1) + c = 0 \implies a + b + c = 0a(1)2+b(1)+c=0⟹a+b+c=0.
