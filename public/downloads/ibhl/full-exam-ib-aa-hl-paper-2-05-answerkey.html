Consider the function f(x)=x2−3x+2f(x) = x^2 - 3x + 2f(x)=x2−3x+2. The graph of y=f(x)y = f(x)y=f(x) is a parabola. Find the x-coordinates of the points where the graph intersects the x-axis.

(a) Write down the key mathematical relationship or initial equation required to model this problem. [5 marks]
(b) Hence, or otherwise, find the exact required analytical solution, showing all working clearly. [9 marks]
Official Examiner Mark Scheme [14 marks] — Final Answer: 1 and 2
To find the x-coordinates of the points where the graph intersects the x-axis, we need to find the values of xxx for which f(x)=0f(x) = 0f(x)=0.

Set the function equal to zero:
x2−3x+2=0x^2 - 3x + 2 = 0x2−3x+2=0

Factor the quadratic equation:
(x−1)(x−2)=0(x - 1)(x - 2) = 0(x−1)(x−2)=0

This gives two possible solutions for xxx:
x−1=0  ⟹  x=1x - 1 = 0 \implies x = 1x−1=0⟹x=1
x−2=0  ⟹  x=2x - 2 = 0 \implies x = 2x−2=0⟹x=2

Therefore, the graph intersects the x-axis at x=1x=1x=1 and x=2x=2x=2. [M1] [A1]
