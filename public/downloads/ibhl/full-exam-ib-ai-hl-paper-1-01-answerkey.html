1 Functions (HL Extensions) [5 marks]
The graph of the function y=f(x)y = f(x)y=f(x) is shown below. The function is of the form f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c. The vertex of the parabola is at (2,−4)(2, -4)(2,−4). The parabola passes through the points (0,0)(0, 0)(0,0) and (4,0)(4, 0)(4,0). Determine the value of aaa.

(a) Write down the key mathematical relationship or initial equation required to model this problem. [2 marks]
(b) Hence, or otherwise, find the exact required analytical solution, showing all working clearly. [3 marks]
Official Examiner Mark Scheme [5 marks] — Final Answer: 111
The general form of a quadratic function is f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c. The vertex form of a quadratic function is f(x)=a(x−h)2+kf(x) = a(x-h)^2 + kf(x)=a(x−h)2+k, where (h,k)(h, k)(h,k) is the vertex. In this case, the vertex is (2,−4)(2, -4)(2,−4), so h=2h=2h=2 and k=−4k=-4k=−4. Thus, the function can be written as f(x)=a(x−2)2−4f(x) = a(x-2)^2 - 4f(x)=a(x−2)2−4.

We are given that the parabola passes through the point (0,0)(0, 0)(0,0). Substitute these coordinates into the vertex form equation:
0=a(0−2)2−40 = a(0-2)^2 - 40=a(0−2)2−4
0=a(−2)2−40 = a(-2)^2 - 40=a(−2)2−4
0=4a−40 = 4a - 40=4a−4
4a=44a = 44a=4
a=1a = 1a=1.

Let's verify with the other given point (4,0)(4, 0)(4,0):
0=a(4−2)2−40 = a(4-2)^2 - 40=a(4−2)2−4
0=a(2)2−40 = a(2)^2 - 40=a(2)2−4
0=4a−40 = 4a - 40=4a−4
4a=44a = 44a=4
a=1a = 1a=1.

Thus, the value of aaa is 1.

Common algebraic trap: Students might try to use f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c and solve a system of equations using the three points. This is more algebraically intensive and prone to errors. Using the vertex form simplifies the problem significantly. [M1] [A1]
