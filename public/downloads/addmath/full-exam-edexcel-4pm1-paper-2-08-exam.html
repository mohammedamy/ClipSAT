A group of nnn students, which includes Ali and Priya, are to be arranged in a straight line for a photograph. The number of different arrangements in which Ali and Priya are not standing next to each other is 360036003600. Find the value of the integer nnn. [7]

Working Space — Show all stages of your mathematical working clearly: [7 marks]
Answer:
Official Examiner Mark Scheme [7 marks] — Final Answer: 777
We can find the number of arrangements where Ali and Priya do not stand next to each other using the complementary method or the insertion (gap) method.

Method 1: Complementary Counting
1. The total number of unrestricted arrangements of the nnn students in a straight line is n!n!n!.
2. Consider the arrangements in which Ali and Priya *do* stand next to each other:
- Treat Ali and Priya as a single block. There are now (n−1)(n - 1)(n−1) entities to arrange, which can be done in (n−1)!(n - 1)!(n−1)! ways.
- Within the block, Ali and Priya can arrange themselves in 2!=22! = 22!=2 ways.
- So, the number of arrangements where they are together is 2(n−1)!2(n - 1)!2(n−1)!.
3. Subtracting this from the total gives the number of arrangements where they are separated:
n!−2(n−1)!=n(n−1)!−2(n−1)!=(n−2)(n−1)!n! - 2(n - 1)! = n(n - 1)! - 2(n - 1)! = (n - 2)(n - 1)!n!−2(n−1)!=n(n−1)!−2(n−1)!=(n−2)(n−1)!

Method 2: Gap Method
1. Arrange the other n−2n - 2n−2 students first, which gives (n−2)!(n - 2)!(n−2)! ways.
2. This creates (n−2)+1=n−1(n - 2) + 1 = n - 1(n−2)+1=n−1 available spaces (including the ends).
3. Placing Ali and Priya into two distinct spaces ensures they are not adjacent: n−1P2=(n−1)(n−2){}^{n-1}\mathrm{P}_{2} = (n - 1)(n - 2)n−1P2​=(n−1)(n−2) ways.
4. Total arrangements: (n−2)!×(n−1)(n−2)=(n−2)(n−1)!(n - 2)! \times (n - 1)(n - 2) = (n - 2)(n - 1)!(n−2)!×(n−1)(n−2)=(n−2)(n−1)!.

Equating this to 360036003600:
(n−2)(n−1)!=3600(n - 2)(n - 1)! = 3600(n−2)(n−1)!=3600
Testing integer values for n≥3n \ge 3n≥3:
- For n=6n = 6n=6: (6−2)(5!)=4×120=480(6 - 2)(5!) = 4 \times 120 = 480(6−2)(5!)=4×120=480
- For n=7n = 7n=7: (7−2)(6!)=5×720=3600(7 - 2)(6!) = 5 \times 720 = 3600(7−2)(6!)=5×720=3600
- For n=8n = 8n=8: (8−2)(7!)=6×5040=30240(8 - 2)(7!) = 6 \times 5040 = 30240(8−2)(7!)=6×5040=30240

Thus, n=7n = 7n=7.

*Common Misconception Trap:* Forgetting that Ali and Priya can switch places within their unit gives n!−(n−1)!=(n−1)(n−1)!n! - (n - 1)! = (n - 1)(n - 1)!n!−(n−1)!=(n−1)(n−1)!, which fails to produce an integer solution among the options. [M1][A1]
