7 Functions, Modulus & Quadratics Standard [7 marks]
Find the set of values of the constant mmm for which the equation
∣2x−6∣=mx+2|2x - 6| = mx + 2∣2x−6∣=mx+2
has exactly two distinct real solutions. [7]
Official Examiner Mark Scheme [7 marks] — Final Answer: −23<m<2-\frac{2}{3} < m < 2−32​<m<2
We consider the function y=∣2x−6∣y = |2x - 6|y=∣2x−6∣ and the line y=mx+2y = mx + 2y=mx+2.

1. Analyze the modulus function:
The graph of y=∣2x−6∣y = |2x - 6|y=∣2x−6∣ consists of two linear rays meeting at the vertex (3,0)(3, 0)(3,0):
y={2x−6,for x≥3 (gradient 2),−2x+6,for x<3 (gradient −2).y = \begin{cases} 2x - 6, & \text{for } x \ge 3 \text{ (gradient } 2\text{)}, \\ -2x + 6, & \text{for } x < 3 \text{ (gradient } -2\text{)}. \end{cases}y={2x−6,−2x+6,​for x≥3 (gradient 2),for x<3 (gradient −2).​

2. Analyze the line y=mx+2y = mx + 2y=mx+2:
The line has a fixed yyy-intercept at (0,2)(0, 2)(0,2) and variable gradient mmm.

3. Lower boundary (passing through the vertex):
The line passes through the vertex (3,0)(3, 0)(3,0) when:
0=m(3)+2  ⟹  m=−23.0 = m(3) + 2 \implies m = -\frac{2}{3}.0=m(3)+2⟹m=−32​.
- If m<−23m < -\frac{2}{3}m<−32​, the line passes below the vertex (3,0)(3, 0)(3,0) and does not intersect the right ray x≥3x \ge 3x≥3.
- At m=−23m = -\frac{2}{3}m=−32​, the line meets the vertex (3,0)(3, 0)(3,0) as its only intersection point on both rays, giving exactly one real solution.
- Therefore, for two distinct solutions, we must have m>−23m > -\frac{2}{3}m>−32​.

4. Upper boundary (parallelism with the right ray):
The right ray has gradient 222.
- If m=2m = 2m=2, the line y=2x+2y = 2x + 2y=2x+2 is parallel to y=2x−6y = 2x - 6y=2x−6 and never intersects the right ray; it intersects only the left ray at −2x+6=2x+2  ⟹  x=1-2x + 6 = 2x + 2 \implies x = 1−2x+6=2x+2⟹x=1 (1 solution).
- If m>2m > 2m>2, the line is steeper than the right ray and starts above it at x=0x = 0x=0, so it only intersects the left ray once and never intersects the right ray.
- Therefore, the line must be less steep than the right ray: m<2m < 2m<2.

5. Verification of two intersections for −23<m<2-\frac{2}{3} < m < 2−32​<m<2:
- Intersection with right ray: 2x−6=mx+2  ⟹  (2−m)x=8  ⟹  x=82−m2x - 6 = mx + 2 \implies (2 - m)x = 8 \implies x = \frac{8}{2 - m}2x−6=mx+2⟹(2−m)x=8⟹x=2−m8​. Since m<2m < 2m<2 and m>−23m > -\frac{2}{3}m>−32​, we have 2−m<832 - m < \frac{8}{3}2−m<38​, which implies x>3x > 3x>3 (valid).
- Intersection with left ray: −2x+6=mx+2  ⟹  (m+2)x=4  ⟹  x=4m+2-2x + 6 = mx + 2 \implies (m + 2)x = 4 \implies x = \frac{4}{m + 2}−2x+6=mx+2⟹(m+2)x=4⟹x=m+24​. Since m>−23>−2m > -\frac{2}{3} > -2m>−32​>−2, m+2>43m + 2 > \frac{4}{3}m+2>34​, which implies 0<x<30 < x < 30<x<3 (valid).

Thus, exactly two distinct real solutions occur when −23<m<2-\frac{2}{3} < m < 2−32​<m<2.

Common Traps:
- Setting m>−2m > -2m>−2 (Choice B) mistakenly uses the slope of the left branch instead of testing when the line crosses the vertex (3,0)(3, 0)(3,0).
- Squaring both sides blindly introduces extraneous roots where mx+2<0mx + 2 < 0mx+2<0.
- Including the endpoints (Choice C) fails to recognize that at m=−23m = -\frac{2}{3}m=−32​ and m=2m = 2m=2 there is only one real solution. [M1][A1]

10 Functions, Modulus & Quadratics Challenging [10 marks]
Find the set of values of the constant kkk for which the equation
∣x2−4∣=2x+k|x^2 - 4| = 2x + k∣x2−4∣=2x+k
has exactly four distinct real solutions. [10]
Official Examiner Mark Scheme [10 marks] — Final Answer: 4<k<54 < k < 54<k<5
To find the number of solutions to ∣x2−4∣=2x+k|x^2 - 4| = 2x + k∣x2−4∣=2x+k, we consider the intersections of the curve y=∣x2−4∣y = |x^2 - 4|y=∣x2−4∣ and the line y=2x+ky = 2x + ky=2x+k.

The curve is defined piecewise:
- Inner arch: y=4−x2y = 4 - x^2y=4−x2 for −2≤x≤2-2 \le x \le 2−2≤x≤2
- Outer branches: y=x2−4y = x^2 - 4y=x2−4 for x<−2x < -2x<−2 and x>2x > 2x>2

1. Intersection with the inner arch (−2≤x≤2-2 \le x \le 2−2≤x≤2):
4−x2=2x+k  ⟺  x2+2x+(k−4)=04 - x^2 = 2x + k \iff x^2 + 2x + (k - 4) = 04−x2=2x+k⟺x2+2x+(k−4)=0
For two distinct real intersections, the discriminant must be strictly positive:
Δ=22−4(1)(k−4)=20−4k>0  ⟹  k<5\Delta = 2^2 - 4(1)(k - 4) = 20 - 4k > 0 \implies k < 5Δ=22−4(1)(k−4)=20−4k>0⟹k<5
At k=5k = 5k=5, Δ=0\Delta = 0Δ=0, so the line is tangent to the inner arch at x=−1∈(−2,2)x = -1 \in (-2, 2)x=−1∈(−2,2), giving only 1 intersection point.

Furthermore, the roots must lie within the interval [−2,2][-2, 2][−2,2]. The lower critical value occurs when the line passes through the corner intercept (−2,0)(-2, 0)(−2,0):
0=2(−2)+k  ⟹  k=40 = 2(-2) + k \implies k = 40=2(−2)+k⟹k=4
At k=4k = 4k=4, the equation becomes x2+2x=0  ⟹  x=0x^2 + 2x = 0 \implies x = 0x2+2x=0⟹x=0 or x=−2x = -2x=−2. Because x=−2x = -2x=−2 is the boundary corner shared with the outer branch, the total number of distinct solutions is 3.

For 4<k<54 < k < 54<k<5, the roots are x=−1±5−kx = -1 \pm \sqrt{5 - k}x=−1±5−k​. Since 0<5−k<10 < 5 - k < 10<5−k<1, we have 5−k∈(0,1)\sqrt{5 - k} \in (0, 1)5−k​∈(0,1), which guarantees both roots strictly lie in (−2,0)⊂(−2,2)(-2, 0) \subset (-2, 2)(−2,0)⊂(−2,2). Hence, there are exactly 2 distinct solutions on the inner arch.

2. Intersection with the outer branches (x<−2x < -2x<−2 or x>2x > 2x>2):
x2−4=2x+k  ⟺  x2−2x−(k+4)=0x^2 - 4 = 2x + k \iff x^2 - 2x - (k + 4) = 0x2−4=2x+k⟺x2−2x−(k+4)=0
The discriminant is:
Δ=(−2)2−4(1)(−(k+4))=4k+20\Delta = (-2)^2 - 4(1)(-(k + 4)) = 4k + 20Δ=(−2)2−4(1)(−(k+4))=4k+20
For 4<k<54 < k < 54<k<5, Δ∈(36,40)>0\Delta \in (36, 40) > 0Δ∈(36,40)>0, yielding roots x=1±k+5x = 1 \pm \sqrt{k + 5}x=1±k+5​.
Since 9<k+5<109 < k + 5 < 109<k+5<10, 3<k+5<10≈3.1623 < \sqrt{k + 5} < \sqrt{10} \approx 3.1623<k+5​<10​≈3.162:
- The larger root satisfies x=1+k+5>4>2x = 1 + \sqrt{k + 5} > 4 > 2x=1+k+5​>4>2 (valid on x>2x > 2x>2).
- The smaller root satisfies x=1−k+5<−2x = 1 - \sqrt{k + 5} < -2x=1−k+5​<−2 (valid on x<−2x < -2x<−2).
Thus, there are always exactly 2 distinct solutions on the outer branches.

Combining both parts, the equation has 2+2=42 + 2 = 42+2=4 distinct real solutions if and only if 4<k<54 < k < 54<k<5.

Common Misconceptions:
- 4≤k≤54 \le k \le 54≤k≤5 incorrectly includes the boundary values k=4k = 4k=4 (corner intersection) and k=5k = 5k=5 (tangency), each of which yields only 3 distinct solutions.
- −4<k<4-4 < k < 4−4<k<4 yields only 2 distinct solutions because one root from the inner arch and one root from the outer branch fall outside their valid domains. [M1][A1]
