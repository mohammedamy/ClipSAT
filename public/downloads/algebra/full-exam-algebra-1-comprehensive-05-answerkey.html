C. 111 ✓
D. 333
Correct Answer: (C) — 111
The function is given by f(x)=ax2+bf(x) = ax^2 + bf(x)=ax2+b. We are given two points that lie on the graph of this function: (−2,13)(-2, 13)(−2,13) and (3,28)(3, 28)(3,28).

Substitute the first point into the equation: 13=a(−2)2+b13 = a(-2)^2 + b13=a(−2)2+b, which simplifies to 13=4a+b13 = 4a + b13=4a+b. (Equation 1)

Substitute the second point into the equation: 28=a(3)2+b28 = a(3)^2 + b28=a(3)2+b, which simplifies to 28=9a+b28 = 9a + b28=9a+b. (Equation 2)

Now we have a system of two linear equations with two variables, aaa and bbb:
1) 4a+b=134a + b = 134a+b=13
2) 9a+b=289a + b = 289a+b=28

To find the value of bbb, we can eliminate aaa. Subtract Equation 1 from Equation 2:
(9a+b)−(4a+b)=28−13(9a + b) - (4a + b) = 28 - 13(9a+b)−(4a+b)=28−13
5a=155a = 155a=15
a=3a = 3a=3

4(3)+b=134(3) + b = 134(3)+b=13
12+b=1312 + b = 1312+b=13
b=13−12b = 13 - 12b=13−12
b=1b = 1b=1
