C. 160160160
D. 120120120

We know that the ratio BR=53\frac{B}{R} = \frac{5}{3}RB​=35​.
We can write B=5kB = 5kB=5k and R=3kR = 3kR=3k for some constant kkk.
It is given that the number of blue pens exceeds the number of red pens by 40 pens, so B−R=40B - R = 40B−R=40.

The total number of pens is B+R=5k+3k=8kB + R = 5k + 3k = 8kB+R=5k+3k=8k.
